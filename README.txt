المتطلبات:
-----------
1. Node.js — حمّله من: https://nodejs.org
   (اختر LTS)

خطوات البناء:
--------------
1. افتح مجلد هذا الملف
2. اضغط Shift + كليك يمين في المجلد → "Open PowerShell window here"
3. نفّذ الأوامر التالية بالترتيب:

   npm install

   npm run build

4. بعد الانتهاء ستجد الملف في مجلد:
   dist\expiry-dashboard.exe

ملاحظات:
---------
- البناء يأخذ 3-5 دقائق أول مرة
- الملف .exe لا يحتاج تثبيت — portable
- البيانات تُحفظ داخل الجهاز
